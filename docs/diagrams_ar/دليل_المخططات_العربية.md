# دليل المخططات العربية

هذه النسخة مخصصة للقراءة في التقرير أو العرض الجامعي. استُبدلت أسماء الجداول التقنية بأسماء عربية مفهومة، مع الإبقاء على الحقول الأساسية اللازمة لفهم البنية الفعلية.

## مفتاح القراءة

| الرمز أو اللون | المعنى |
|---|---|
| `PK` | مفتاح أساسي يميز السجل داخل الكيان |
| `FK` | مفتاح أجنبي يربط الكيان بكيان آخر |
| `1 : متعدد` | سجل واحد في الكيان الأب يرتبط بعدة سجلات في الكيان التابع |
| `1 : 1` | علاقة واحد إلى واحد، ويثبتها القيد الفريد في قاعدة البيانات |
| الأزرق | العمليات أو الكيانات العامة |
| الأخضر | مقدمو الخدمات والتوثيق |
| الأصفر | الخدمات والكتالوج |
| البرتقالي | الطلبات والتسليم |
| الوردي | الدفع والعمولات |
| البنفسجي | المراجعات والمحادثات |
| السماوي | الإشعارات والسجل التدقيقي |

## محتويات الصور

**الشكل (1): مخطط الكيانات والعلاقات ERD.** يعرض جميع كيانات قاعدة البيانات الفعلية وأهم الحقول والمفاتيح والعلاقات الرسمية. أسماء الكيانات والحقول بالعربية، وتظهر العلاقة على السهم مع الحقل والكاردينالية.

**الشكل (2): مخطط الفئات.** يوضح الفئات المنطقية في النظام، مثل المستخدم وملف مقدم الخدمة والخدمة والطلب والدفع والتقييم، مع الخصائص الأساسية والعلاقات.

**الشكل (3): مخطط السياق / المستوى الصفري.** يوضح النظام ككل والكيانات الخارجية وتدفقات البيانات الرئيسية دون الدخول في التفاصيل الداخلية.

**الشكل (4): DFD المستوى الأول.** يوضح العمليات الفعلية في المشروع، ومخازن البيانات، والبيانات الداخلة والخارجة، مع فصل الحسابات والخدمات والتوثيق والطلبات والدفع والمراجعات والإدارة.

**الشكل (5): DFD المستوى الثاني.** يفصل عملية توثيق مقدم الخدمة لأنها عملية مركبة تشمل الملف والمستندات وطلب التوثيق والمراجعة والقرار والإشعار.

**الشكل (6): مخطط بنية قاعدة البيانات.** يقدم العرض التفصيلي للحقول الفعلية لكل كيان، ويستخدم الأسماء العربية لتسهيل القراءة، مع إبراز PK وFK.

العلاقات المعروضة في الصور هي العلاقات المعرفة رسميًا في `db.sqlite3`. أما العلاقات الدلالية التي لا يفرضها المفتاح الأجنبي، مثل معنى دور المستخدم في بعض الحقول، فقد تم شرحها منفصلة في تقرير تحليل قاعدة البيانات تحت قسم **Inferred Relationships**.
